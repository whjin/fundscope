# FundScope 会员功能开发方案

> 面向个人开发者：为 FundScope 规划增值功能与会员体系的落地文档。
> 核心结论：**先补齐商业化地基（真实认证 + 支付 + 分层），再上用户真正需要的核心增值，最后做差异化卖点。**

---

## 一、现状诊断

FundScope 已有扎实的功能底座，但商业化地基缺位：

**已有能力**（`app.js` / `shared.js` / `server.js`）
- 基金搜索（内置基金列表 `data.json`，combobox 模糊匹配）
- 持仓明细表（重仓股、代码、涨跌幅、占比、市值、增减持变化）
- 占比分布环形图、市值排行柱状图（ECharts）
- 实时股票行情（腾讯 / 新浪行情接口）
- 净值、基金经理、近 1 年收益率展示

**商业化短板**
| 项 | 现状 | 问题 |
|---|---|---|
| 登录 | `localStorage` 模拟（`auth.js`），无真实后端 | 无法真正鉴权、无法 gate 功能 |
| 支付 | `$9.99/月` 仅定价页，未接入 | 收不到钱 |
| 分层 | 单一 Pro 档，无免费/付费分层 | 无漏斗、无拉新 |
| 配额 | 无用量限制 | 增值功能无法变现 |

## 二、功能扩展方向（按类别）

### A 强化核心分析（留存 · 选基刚需 · P0–P1）
- 📈 **历史净值走势曲线**（多期净值曲线，选基决策第一需求）— **P0**
- ⚖️ **多基金横向对比**（多基金并排：持仓重叠度、前十大重仓对比）— **P0**
- 🔄 **多期调仓对比时间线**（现有仅最近 2 期增减持，扩展为完整调仓历史）— **P1**
- 🏭 **行业 / 板块穿透分布**（把重仓股按行业归类，看行业配置）— **P1**

### B 组合与跟踪（粘性 · 长期使用 · P1）
- ⭐ 自选基金 / 组合管理（用户建立基金篮，组合视图）
- 🔔 调仓变动预警（基金调仓通知）
- 💹 估值 / 定投计划提醒
- 📊 净值与业绩跟踪 — **P2**

### C 深度洞察（差异化付费点 · P1–P2）
- 🤖 **AI 持仓解读**（自然语言总结持仓变化、给解读）— **P1**
- 📄 一键生成持仓分析报告（PDF / 数据导出）— **P2**
- 👤 基金经理深度分析（管理多只基金、历史业绩）— **P2**
- 🗂️ 同类基金筛选榜单 — **P2**

## 三、会员分层建议

| 档位 | 定位 | 内容 |
|---|---|---|
| **Free** | 拉新 / SEO / 广告位 | 每日限额查询 N 次、基础图表、基础基金搜索 |
| **Pro $9.99/月** | 变现 | 无限查询、历史净值与多期调仓对比、横向对比、行业穿透、调仓预警、报告导出、优先邮件支持 |

- 7 天免费试用（无需信用卡）
- 随时取消、无锁定

## 四、优先级与落地顺序

优先级依据个人投资者「选基 → 看懂 → 跟踪 → 决策」路径：

| 阶段 | 内容 | 优先级 | 价值 |
|---|---|---|---|
| ① 地基 | 真实认证 + 支付接入 + 用量 gating + 订阅管理 | **P0** | 让"会员"真正成立，否则一切增值无法变现 |
| ② 核心 | 历史净值走势 + 多基金横向对比 | **P0** | 选基刚需，付费转化主力 |
| ③ 粘性 | 多期调仓对比 + 行业穿透 + 自选组合 + 调仓预警 | **P1** | 形成"每周回来看一次"的习惯 |
| ④ 差异 | AI 解读 + 报告导出 + 基金经理分析 + 同类筛选 | **P2** | Pro 溢价卖点，拉开与竞品差距 |

## 五、技术落地要点（基于现有代码结构）

### 5.1 商业化地基
- **认证**：接入真实账户体系（OAuth Google/GitHub + 邮箱密码），替换 `auth.js` 的 localStorage 模拟；后端维护用户表与会话。
- **支付**：接入 LemonSqueezy / PayPal 订阅，绑定到用户；Webhook 更新订阅状态。
- **分层与 gating**：`server.js` 中为 API 增加鉴权中间件 + 用量配额（如每日查询次数、导出次数）；前端按会员等级渲染功能入口。
- **配额**：Free 每日查询 N 次，超出提示升级。

### 5.2 核心增值（示例接口）
```
GET /api/fund/netvalue?code=xxx&range=1y/3y/all     # 历史净值走势
GET /api/fund/compare?codes=a,b,c                   # 多基金横向对比
GET /api/fund/holdings/history?code=xxx             # 多期调仓时间线
GET /api/fund/industry?code=xxx                     # 行业穿透分布
GET /api/user/portfolio                             # 自选组合（需登录）
POST /api/user/alerts                                # 调仓预警（需登录）
```

### 5.3 前端
- 基于 `app.js` 现有 ECharts 渲染扩展：折线图（净值）、对比图表（多基金）、时间线组件（调仓）。
- `pricing.html` 扩为双档位对比页，接入真实订阅跳转。

## 六、优先级链路

```
商业化地基 (P0)  →  A 强化核心分析 (P0-P1)  →  B 组合与跟踪 (P1)  →  C 深度洞察 (P1-P2)
     │                     │                        │                     │
  认证/支付/分层          历史净值/横向对比        自选/预警/跟踪         AI解读/报告/经理分析
```

> 注：优先级与功能项为产品规划建议，实际取舍请结合用户反馈与市场验证调整。
